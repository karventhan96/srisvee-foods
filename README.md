# Nendram Naturals — Next.js Website

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing

Replace:
- [PRICE] values
- phone number
- WhatsApp number
- email
- location
- product images
- placeholder testimonials

The page is based on the supplied Designer-2.pdf layout and content. It is intentionally built as a clean responsive marketing site and can later be connected to a real cart/payment system.
